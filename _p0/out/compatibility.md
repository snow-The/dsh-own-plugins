**通过。** 所有插件在这几个版本上都不会被宿主预检禁用。

护栏自带 `--self-test`：注入四个已知清单（带上界 / 下界过高 / 范围坏掉 / 正确对照组）断言护栏的行为。**一个不能失败的护栏等于没有护栏**，所以要能证明它落闸。

## 这个 CI 判定什么 / 不判定什么

- **判定**：宿主预检会不会因为这个插件的 `peerDependencies` 而把它 `disabled`。
- **不判定**：插件的 API 调用是否仍与新版宿主兼容。**纯下界声明在门禁上永远通过** —— 真正的破坏性变更只能靠测试与实跑发现。
- 所以它是**必要不充分**：挡住"静默被禁用"这一整类故障，但不替代功能测试。**② 的复验提醒正是为补这个缺口而设。**
